# AZ-900 – Azure Fundamentals Resources

This README contains useful resources and interactive demos for **Microsoft Azure Fundamentals (AZ-900)**.

## 📚 Resources

### 1. Microsoft Certified: Azure Fundamentals

Explore the official Microsoft certification page for **Azure Fundamentals (AZ-900)**.

The page provides information about:

- AZ-900 certification
- Skills measured
- Certification details
- Exam information
- Practice assessment
- Preparation resources

🔗 [Microsoft Certified: Azure Fundamentals](https://learn.microsoft.com/en-us/credentials/certifications/azure-fundamentals/?practice-assessment-type=certification)

### 2. AZ-900 Demo Simulator

Use this simulator to practice Azure Fundamentals concepts and get familiar with AZ-900-style questions.

🔗 [AZ-900 Demo Simulator](https://ankitcloudlab.in/)

### 3. Microsoft Azure Global Datacenter

Explore Microsoft's global Azure datacenter infrastructure using the interactive globe.

This is useful for understanding:

- Azure global infrastructure
- Azure regions
- Azure datacenter locations
- Geographic distribution of Azure services
- Global Azure presence

🔗 [Explore Microsoft Azure Datacenters](https://datacenters.microsoft.com/globe/explore)

---

### 4. Azure for Students – Free Azure Account

Students can explore Azure and build cloud solutions using Azure for Students.

The offer provides access to Azure services without requiring a credit card, subject to Microsoft's current eligibility and offer terms.

You can use it to practice:

- Azure Virtual Machines
- Azure Storage
- Azure App Services
- Azure Functions
- Azure Databases
- Azure AI services
- Networking
- Cloud administration

🔗 [Build in the Cloud with Azure for Students](https://azure.microsoft.com/en-us/free/students/?cid=msft_learn_98802cd5-8434-6c84-d584-7b1cdb90c5e7)

## 🎯 Recommended Learning Flow

For AZ-900 learners, the following sequence is recommended:

1. **Explore the AZ-900 Certification**
   - Review the official Microsoft Azure Fundamentals certification page.
   - Understand the skills measured in the exam.
   - Review the certification and exam information.
   - Attempt the Microsoft practice assessment.

2. **Explore Azure Global Infrastructure**
   - Open the Azure Datacenter Explorer.
   - Explore Azure regions and datacenter locations.
   - Understand the concepts of regions, region pairs, and global infrastructure.

3. **Create an Azure Student Account**
   - Sign up for Azure for Students if eligible.
   - Explore the Azure Portal.
   - Create and experiment with basic Azure resources.

4. **Practice AZ-900 Questions**
   - Use the AZ-900 Demo Simulator.
   - Attempt practice questions.
   - Review incorrect answers.
   - Revisit the corresponding Azure concepts.
